# Yue Xu — Academic Homepage

Academic homepage of Yue Xu (许越), South China University of Technology.

## Update

Edit `index.html` for content, `styles.css` for presentation, and `script.js` for interactions. The portrait is stored in `assets/yue-xu-camera.jpg`.

## Publish

GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).
